          Settings changes apply to the live overlay when you press Save

          How often each idle moment plays in each mood. Numbers are weights; the gold % is the real chance. 0 = never.

          Value = approximate coin price, only used to order the queue (costlier first); never shown on stream. Gift name must match TikTok exactly (spaces and capitals don't matter). Add other spellings as aliases. “Big” gifts jump the queue with a gold flash.

          Going live, step by step
          1. Double-click Start Zuri.bat in the tiktok-live folder (keep its window open).
          2. This Control Room opens. Check the three pills at the top are green.
          3. In TikTok LIVE Studio, the Link source points at http://localhost:7777/live.html, size 1080×1920, audio ON.
          4. Go live. The TikTok pill turns green within ~15 seconds.
          What the pills mean

          TikTok: connected to your LIVE (grey = test mode / not live yet). Overlay: LIVE Studio's page is running and its size (should be 1080×1920). Sound: the overlay is allowed to play sound.

          If something looks wrong

          Overlay pill red → in LIVE Studio, right-click the Link source → Refresh. “2 overlays” warning → close extra browser tabs showing live.html. Sound blocked → enable audio on the Link source.
